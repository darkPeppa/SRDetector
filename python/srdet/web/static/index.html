Исследования (сканы параметров)

Каждое исследование отвечает на один вопрос: меняется один параметр (иногда два — тогда второй рисуется отдельными линиями), всё остальное закреплено. U — единичные кейсы (один канал или кластер из 7 сот, чтобы изолировать эффект), B — пучки и источники, F — сравнение на полном детекторе. Раскройте «почему так», чтобы увидеть, почему выбраны именно эти условия и значения, чего ожидать и как читать график.

От какой конфигурации стартует поиск и что в ней закреплено для всех кандидатов (энергия пучка, длина…).

3. Что меняем — свободные параметры

Каждому параметру — короткое имя (его можно использовать в формулах). Диапазон: границы и единицы; «log» — точки равномерны в логарифме (для величин, меняющихся в разы). Варианты — перебор значений.
имяключ конфигурациитипзначения
Вычисляемые параметры (необязательно)
Ключ конфигурации, который считается из свободных параметров — например, шаг сот из диаметра и стенки, чтобы каждая точка была допустимой геометрией. Числа в базовых единицах: мм, кэВ, градусы.

4. Цель — что считаем «лучше»

Одно число на кандидата. Можно выбрать метрику или собрать формулу (×, ÷, +, −, log, sqrt, min, max).
добавить метрику: готовые:

Ограничения — требования, которые обязаны выполняться

Кандидат, нарушивший хоть одно, считается недопустимым, как бы хороша ни была цель. Требования лучше задавать здесь, а не весами в цели: «r50 ≤ 120 мкм» понятнее и устойчивее.

5. Метод поиска и статистика прогонов

Поиск идёт ступенями: много кандидатов на малой статистике → лучшая доля пересчитывается точнее → уточнение вокруг лучшего → проверка повторами. Справа — план с числом симуляций.
