# Legacy code (до рефакторинга)

Исходное приложение сохранено без изменений для сравнения и не собирается корневым CMakeLists.
Найденные в нём ошибки описаны в [docs/physics.md](../docs/physics.md#7-что-было-не-так-в-legacy-коде-legacy).
Ближайший аналог в новой системе с исправленными багами — конфигурация
`configs/detector/legacy_like.yaml` и вариант `legacy_materials_L30` в исследовании F01.

`srdet.in` и `srdet.out` — остатки примера Geant4 B1 (протоны 210 МэВ, Geant4 9.6), к этому
детектору они не относятся.
